Залить BigBossYan на GitHub

Ассистент может залить через gh, если ты уже вошёл в GitHub CLI. Ниже — ручной путь через сайт.

Шаг 1. Войди

Открыть вход в GitHub

Шаг 2. Создай репозиторий

Создать репозиторий
  1. Repository name: bigbossyan
  2. Public
  3. Без README / .gitignore / license
  4. Create repository

Шаг 3. Залей файлы

  1. uploading an existing file
  2. Папка Desktop\ЯН\bigbossyan-pwa → Ctrl+A → перетащи
  3. Commit changes

В корне репозитория должен быть index.html.

Шаг 4. Pages

  1. Settings → Pages
  2. Branch: main, папка / (root)
  3. Save → подожди 1–2 минуты

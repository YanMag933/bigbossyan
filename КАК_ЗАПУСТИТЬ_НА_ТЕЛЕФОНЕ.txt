BigBossYan — как запустить на телефоне
======================================

Путь А (рекомендую): GitHub Pages — HTTPS
----------------------------------------
1. Войди на https://github.com
2. Создай репозиторий: bigbossyan (Public)
3. Залей содержимое папки Desktop\ЯН\bigbossyan-pwa
   (в корне должен быть index.html)
4. Settings → Pages → Branch main → / (root) → Save
5. Ссылка: https://ТВОЙ_НИК.github.io/bigbossyan/
6. Телефон: открой ссылку → Установить / На экран «Домой»

Или открой ЗАЛЕЙ_НА_GITHUB.html в этой папке — пошагово с кнопками.

Путь Б: Wi-Fi с компьютера
-------------------------
1. ЗАПУСК.bat на ПК
2. Телефон в той же Wi-Fi: http://IP:8766
   (PWA-установка по HTTP часто не работает — лучше путь А)

После установки
---------------
1. Переключай Life RPG ↔ OnboardOps
2. Отмечай задачи в Штабе / Плане
3. Смотри % и аналитику
4. Пиши победы и заметки

Данные хранятся на телефоне. Очистка данных сайта = сброс прогресса.
